# Gestor de Tareas en Python

Gestor de tareas de consola que guarda y carga las tareas desde un archivo JSON (`tareas.json`), que se crea en la misma carpeta del programa.

## Funcionalidades

- Agregar tareas.
- Listar tareas pendientes.
- Eliminar una tarea por número.
- Las tareas se conservan al cerrar el programa.

## Requisitos

- Python 3.x
- No necesita librerías externas.

## Uso

```bash
git clone https://github.com/pagarcia22/Gestor_tareas_basico.git
cd Gestor_tareas_basico
python gestor.py
```

Menú del programa:

```
--- GESTOR DE TAREAS ---
1. Agregar tarea
2. Listar tareas
3. Eliminar tarea
4. Salir
```
